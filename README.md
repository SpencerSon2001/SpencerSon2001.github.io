# Jianli Sun — Academic Homepage

A responsive, static academic homepage suitable for GitHub Pages.

## Deploy with GitHub Pages

1. Create a repository named `SpencerSon2001.github.io` (or any repository for a project site).
2. Upload everything in this folder, preserving the `assets` directory.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. The site will be available after GitHub finishes deployment.

No build step or external dependencies are required.
